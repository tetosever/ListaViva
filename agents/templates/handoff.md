# Consegna del task

- Issue / branch / commit:
- Risultato rispetto ai criteri:
- File modificati e ragione:
- Contratti o migrazioni cambiati:
- Verifiche eseguite, comandi ed esiti:
- Verifiche non eseguite e motivo:
- Rischi, blocchi e dipendenze:
- Prossima azione proposta:

Allegare evidenze concise. Separare risultati osservati da ipotesi. Non dichiarare Done prima del merge della PR e dell'evidenza richiesta.
